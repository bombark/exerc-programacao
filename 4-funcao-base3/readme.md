# Modularização de uma Matriz

Faça a função soma_linha_da_matriz tal que ela receberá uma matriz e seu respectivo tamanho e retorna a soma de uma linha

Posteriormente, faça uma função que some todos os elementos de uma coluna da matriz.


# Conceitos a aprender

- Passagem de matriz como parametro
- Aumento na quantidade de parametros para depois comentar sobre struct e class
