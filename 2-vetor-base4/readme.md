# Maior e Menor Valor

Faça um programa que leia 6 números inteiros para um vetor. Inverta a ordem dos elementos no próprio vetor (o primeiro elemento troca de lugar com o último, o segundo com o penúltimo, etc.) e imprima o vetor resultante.

Conceito praticado: Manipulação avançada de índices e algoritmos de troca (swap).
