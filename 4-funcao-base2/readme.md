# Modularização de um Vetor

Dado o código que declara um vetor de inteiros com capacidade para 5 elementos. Peça ao usuário para digitar os 5 números, armazene-os no vetor e, em seguida, exiba todos os valores na tela.

Modularize o programa em duas funções, a primeira função para ler o vetor e a segunda para mostrar o vetor.


# Conceitos a aprender

- Passagem de vetor como parametro
