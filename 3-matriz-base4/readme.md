# Matriz Transposta

Faça um programa que leia uma matriz de 2 linhas por 3 colunas. Em seguida, crie uma matriz transposta (onde as linhas viram colunas e vice-versa, resultando em uma matriz 3x2) e exiba o resultado.

Conceito praticado: Manipulação avançada de índices invertidos (matriz[i][j] para transposta[j][i]) e múltiplos vetores bidimensionais.
