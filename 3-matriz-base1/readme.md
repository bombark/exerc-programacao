# Leitura e Exibição de uma Matriz

Crie um programa que declare uma matriz de inteiros de tamanho 3x3. Peça para o usuário preencher todos os elementos via teclado e, em seguida, exiba a matriz formatada na tela no formato de grade (linhas e colunas).

Conceito praticado: Declaração de matrizes, uso de laços for aninhados (i para linhas e j para colunas) e formatação de saída.
