# Leitura e Impressão de Elementos

Crie um programa que declare um vetor de inteiros com capacidade para 5 elementos. Peça ao usuário para digitar os 5 números, armazene-os no vetor e, em seguida, exiba todos os valores na tela.

Conceito praticado: Declaração de vetores, preenchimento via cin e exibição via cout.
