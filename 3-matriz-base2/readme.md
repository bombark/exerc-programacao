# Soma da Diagonal Principal

Escreva um programa que leia uma matriz quadrada de ordem 3 (3x3) de números inteiros. Calcule e mostre apenas a soma dos elementos da diagonal principal (onde a linha é igual à coluna, como a posição [0][0], [1][1] e [2][2]).

Conceito praticado: Condicionais aplicadas a índices e identificação de padrões geométricos em matrizes.
